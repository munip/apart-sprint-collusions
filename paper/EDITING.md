# Editing the paper

The paper is LaTeX in the Apart sprint template layout (single column, Old Standard TT font in `fonts/`, OFL licence).
It needs **XeLaTeX** (or tectonic). Edit the text files, then rebuild the PDF. Keep sections 1-6 plus Code and Data within 8 pages.

| File | What it holds |
|---|---|
| `main.tex` | title/authors, abstract, 1 Introduction, 2 Related Work, 3 Methods, 5 Discussion and Limitations, 6 Conclusion, Code and Data, Author Contributions, LLM Usage Statement |
| `results_llm.tex` | Section 4, Results (market, SWE RQ1-RQ3), Tables 1-2, Figure 2 |
| `appendix.tex` | appendices: scripted-agent validation, chain-of-monitors design (topology sketch), per-episode table, reproduction |
| `tab_swe_episodes.tex` | generated per-episode table (do not edit by hand; regenerate with the script) |
| `refs.bib` | references |
| `figs/` | figures; `fig_llm_*.pdf` are generated by `analysis/llm_study.py` |

Build:

- Windows: `powershell -ExecutionPolicy Bypass -File paper\build.ps1` (add `-Figures` to regenerate figures from `runs\`)
- macOS/Linux: `bash paper/build.sh`

Easiest LaTeX install on Windows: `winget install tectonic` (one executable; fetches packages on first build).
Every number in the text is printed by `python paper/analysis/llm_study.py runs/peer_study runs/market_entrant --out paper/figs`, so edits to numbers can be checked against the data.
