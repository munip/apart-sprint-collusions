# Editing the paper

The paper is plain LaTeX. Edit the text files, then rebuild the PDF.

| File | What it holds |
|---|---|
| `main.tex` | title, abstract, introduction, related work, trusted components (incl. Fig. 1), environments and design |
| `results_llm.tex` | Section 5, results (market, SWE RQ1-RQ3) and Tables 1-2 |
| `discussion.tex` | Section 6, discussion and next steps |
| `limitations.tex` | Section 7, limitations, constraints and open questions |
| `appendix.tex` | appendices: scripted-agent validation, per-episode table, reproduction commands |
| `tab_swe_episodes.tex` | generated per-episode table (do not edit by hand; regenerate with the script) |
| `refs.bib` | references |
| `figs/` | figures; `fig_llm_*.pdf` are generated by `analysis/llm_study.py` |

Build:

- Windows: `powershell -ExecutionPolicy Bypass -File paper\build.ps1` (add `-Figures` to regenerate figures from `runs\`)
- macOS/Linux: `bash paper/build.sh`

Easiest LaTeX install on Windows: `winget install tectonic` (one executable; fetches packages on first build).
Every number in the text is printed by `python paper/analysis/llm_study.py runs/peer_study runs/market_entrant --out paper/figs`, so edits to numbers can be checked against the data.
